# Python 课程授课工作台与学习实验室

本项目服务《Python程序设计基础与应用》8 周、32 学时课程，提供两个彼此独立的直达入口，不设置登录页，也不进行课堂同步：

- `#/teacher`：教师授课工作台。按 16 次课提供课程设计目的、学情、目标、重点难点、系统知识讲授、案例、90 分钟详案、扩展逐字稿、评价证据和现场 Python 编辑讲授。
- `#/student`：学生学习实验室。学生自主选择对应课程，完成关键知识诊断、案例实验、代码运行、错误分类提示和应用变式挑战。

## 离线运行

双击课程包同级目录中的 `启动Python课程网站.cmd` 或 `打开Python学生端.cmd`。入口会先检查离线服务，必要时自动启动，再打开对应页面。服务在后台运行，不依赖 Codex、Node.js 或互联网；安装登录启动项后，监护程序还会在服务意外退出时自动恢复。

- 教师端：`http://127.0.0.1:端口/#/teacher`
- 学生端：`http://127.0.0.1:端口/#/student`

课程网页、教材封面、Python 运行环境及 `pandas`、`matplotlib` 练习依赖均已包含在构建产物中。启动后断开互联网，教师端、学生端、知识诊断、案例练习和课程指定的浏览器 Python 代码运行均不依赖外网。

本机使用只需打开上述地址。若需要让同一局域网内的学生设备访问，使用本机当前局域网地址，例如 `http://192.168.3.5:5173/#/student`；首次使用时，以管理员身份双击 `配置局域网访问（管理员）.cmd`，并确保 Windows 网络配置为“专用网络”。跨互联网、不同 VLAN、访客网络或被学校网络策略隔离的设备无法仅靠本地离线网站保证互通，需要由学校网络管理员提供可达路由或部署到校内服务器。

## 面向学生的公网链接

若需要把链接直接发给学生、在任意有网设备上打开，请将本静态网站发布到 HTTPS 静态托管。仓库已提供 GitHub Pages 自动发布工作流；请按 `PUBLIC_DEPLOYMENT.md` 操作。发布完成后使用公开地址加 `#/teacher` 或 `#/student`，原有教师端、学生端和本地离线入口均保留不变。

## 教学设计

每次课按 90 分钟有效课堂时间组织：10 分钟检索与诊断，25 分钟系统讲授与教师现场编码，20 分钟代码预测/纠错，25 分钟“12 分钟结对构建 + 7 分钟角色互换 + 6 分钟个人微验证”，10 分钟学习证据整理与迁移。后两项强调形成性评价，不在网站中设置提交队列、作业批改或课堂控制功能。

课程从 Python 基础语法、控制流、内置数据类型、函数与模块完整推进至文件、异常、测试、对象、数据统计与可视化、HTTP/JSON 和综合项目。贯穿案例为匿名校园活动报名与服务数据工具：输入与校验 → 结构化记录 → 文件与数据处理 → 统计和图表 → 公开 JSON → 可信交付。

AI 能生成候选代码，却不能替人澄清需求、发现约束、验证边界、判断数据质量、解释结果或承担责任。课堂要求学生先写规格、预测或测试，再审查 AI 输出；不上传真实个人信息、账号、密钥、未脱敏数据或受限资料。

## 运行边界

- Python 代码由各自浏览器中的本地 Pyodide 执行；项目不运行、保存或传输学生代码。
- Pyodide、pandas 和 Matplotlib 均随课程包提供；首次加载不需要外网，但会占用一定本机内存。
- 当前版本不构成真实身份认证或作业平台；若面向正式教学部署且需要账号、成绩或个人数据，应由学校接入统一认证、HTTPS、持久化、授权、审计和隐私合规措施。
