# 公网部署说明

本课程网站已经是纯静态网站：教师端、学生端、课程资料、浏览器 Python 运行环境和课程所需的 `pandas`、`matplotlib` 资源均随网站文件发布。部署到 HTTPS 静态托管后，教师和学生可使用同一个公开链接，不依赖教师电脑、局域网、Codex 或课堂网络。

## 推荐方案：GitHub Pages

1. 在自己的 GitHub 账号或学校组织中创建一个私有或公开仓库。
2. 将本项目全部上传到该仓库，并将默认分支命名为 `main`。
3. 仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。
4. 推送 `main` 分支。仓库内的 `.github/workflows/deploy-course-site.yml` 会自动构建并发布网站。
5. 在 Actions 页面等待工作流完成，打开其显示的 `github.io` HTTPS 地址。教师地址追加 `#/teacher`，学生地址追加 `#/student`。

示例：

```text
https://你的账号.github.io/你的仓库/#/teacher
https://你的账号.github.io/你的仓库/#/student
```

## 发布前检查

- 教师端和学生端不需要登录，学生不需要与教师电脑同步。
- 每位学生的代码在自己的浏览器中运行；网站不会收集、保存或上传学生代码。
- 首次打开时浏览器会下载本地 Python 运行资源；加载完成后，同一次访问中的代码练习可离线运行。
- 正式公开发布前，请确认不包含真实学生信息、账号、密钥、未脱敏数据或受版权限制的材料。

## 运行边界

“任何有网的设备均可访问”需要一个持续可用的公网 HTTPS 托管地址。离线电脑上的 `127.0.0.1` 地址和局域网 IP 地址无法天然提供跨互联网访问。GitHub Pages、学校静态服务器或经学校批准的云静态托管均可满足该部署条件。
